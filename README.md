# YABI Location

Public website and private operations platform for YABI Location, a Belgian
commercial van rental business.

## Pages

- `index.html` - French homepage
- `contact.html` - French contact and quote page
- `en.html` - English homepage
- `contact-en.html` - English contact and quote page
- `portal/` - role-based customer and operations portal
- `convex/` - private data, access control, workflows, audit history and APIs
- `media-worker/` - signed private uploads and downloads backed by Cloudflare R2

The live UI is hosted on Cloudflare Pages. The application is intentionally
connected to the Convex development deployment:

```text
https://kindhearted-caiman-242.eu-west-1.convex.site/api/quotes
```

## Portal roles

- Administrator: accounts, role codes, customers, fleet, rentals, reports and audit
- Employee: customers and day-to-day vehicle operations
- Customer: personal details, own rentals and reports
- Mechanic: fleet visibility, maintenance and reports
- External worker: active rentals, inspections, handovers and reports

Access codes are generated by an administrator, stored only as keyed hashes,
and shown once. Browser sessions are revocable and role checks are repeated on
every backend operation.

Vehicle photos and signatures never use a public bucket. Convex creates a
short-lived signed request and the R2 Worker confirms the completed upload back
to Convex before evidence can be attached to an operation.

## Local checks

```bash
npm run check
node --check portal/portal.js
node --check script.js
npm run check:media-worker
```

## Development services

```bash
npx convex dev
npm run media:deploy
```

Required Convex deployment variables are documented in `.env.example`.
`MEDIA_SIGNING_SECRET` and `MEDIA_CALLBACK_SECRET` must contain the same values
as the corresponding Cloudflare Worker secrets. Never expose them to browser
JavaScript.

## Deploy the static site

```bash
npx wrangler pages deploy .deploy/cloudflare-pages --project-name yabi-location --branch main
```

The private portal is available at `/portal/`. It is deliberately excluded
from search-engine indexing.
