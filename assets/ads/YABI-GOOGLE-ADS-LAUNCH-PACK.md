# YABI Location — Google Ads launch pack

## Campaign approach

Start with two separate high-intent Search campaigns so French and Dutch are never mixed inside one ad:

- `BE | Search | Utilitaire mensuel | FR`
- `BE | Search | Bestelwagen maandhuur | NL`

Use the same visual asset group for Search image assets and Performance Max. Keep Display/Performance Max focused on remarketing until the account has reliable quote-conversion data.

Primary conversion: successful quote-form submission.

Secondary conversions: qualified phone call and WhatsApp contact. Portal logins, ordinary page views, and application starts must not be counted as primary advertising conversions.

## Shared setup

- Business name: `YABI Location`
- Final URL: `https://yabilocation.com/#devis`
- Display path 1: `utilitaire`
- Display path 2: `mensuel`
- Recommended CTA: `Demander un devis` / `Offerte aanvragen`
- Location: Belgium; use Presence targeting, not people merely interested in Belgium.
- Languages: one French campaign and one Dutch campaign.
- Bidding at launch: maximize conversions only after quote submission tracking is confirmed; otherwise begin with controlled click bidding while collecting clean conversion data.

## Negative-keyword starter list

- free / gratuit / gratis

- buy / acheter / kopen
- used / occasion / tweedehands
- parts / pièces / onderdelen

## Conversion and quality checklist before spending

1. Submit a real test quote and confirm exactly one `quote_submitted` conversion.
2. Confirm the success event fires only after the backend accepts the request.
3. Add call reporting and count only qualified calls, not every click on the phone number.
4. Keep the portal URL excluded from Final URL expansion.
5. Preview every French and Dutch asset combination before publishing.
6. Check mobile landing speed and quote-form completion from a real phone.
7. Review search terms and add negatives weekly during the first month.
8. Judge winners by qualified quote cost and rental value, not click-through rate alone.
